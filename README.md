# JZelda

JZelda è un progetto universitario sviluppato in Java,
ispirato al gameplay del classico The Legend of Zelda.

## Tecnologie

- Java 21
- Eclipse IDE
- Java Swing
- Git e GitHub

## Avvio

1. Importare il progetto in Eclipse.
2. Verificare che il JDK del progetto sia Java 21.
3. Eseguire la classe `it.jzelda.JZelda`.

## Stato del progetto

Configurazione iniziale completata.
La finestra Swing di prova viene visualizzata correttamente.

Le funzionalità di gioco saranno implementate progressivamente.
